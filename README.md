## Hardware editor

Made in kicad 10.0.4

## How to compile

1. Follow Zephyr info : https://docs.zephyrproject.org/latest/develop/getting_started/index.html
2. Follow CLion setup info: https://docs.zephyrproject.org/latest/develop/tools/clion.html
3. Open project in CLion, project path to open is the folder where is the top CMakeLists.txt file (at the moment of writing it is 'software/fox-attenuator' folder)
4. Run the RP2040-Zero board in the boot mode and then select "flash" target in CLion and run build.
